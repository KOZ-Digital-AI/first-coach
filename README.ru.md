# Первый тренер · Бірінші бапкер · FIRST COACH

**Бесплатная открытая футбольная школа для детей.**
60 упражнений с анимацией, план на 4 недели, тесты и прогресс — на казахском, русском и английском.
Без почты и паролей, работает без интернета даже на недорогом телефоне.

## Миссия

У каждого ребёнка должен быть хороший первый тренер.

Получит ли ребёнок нормальные тренировки, до сих пор зависит от того, где он родился, есть ли рядом академия
и могут ли родители за неё платить. При этом тренерских знаний в мире огромное количество — просто они разрознены
и недоступны. «Первый тренер» превращает эти знания в открытую систему, которой может бесплатно пользоваться любой:

**оценка → план → тренировка → замер → рост** — с одного телефона, с мячом и местом 3×3 метра.

Главная метрика проекта: сколько детей реально улучшили навык благодаря бесплатным открытым тренерским знаниям.

## Что получает ребёнок

| | |
|---|---|
| **Профили игроков** | «Кто тренируется?» — ник, аватар и по желанию ПИН-код. Братья, сёстры или целый класс могут заниматься с одного телефона или школьного планшета. Данные не покидают устройство. |
| **План на 4 недели** | Пять вопросов (возраст, цель, что есть под рукой, где тренируешься, сколько времени) и самооценка по пяти навыкам. Тренировка — от 10 до 30 минут. |
| **60 упражнений с анимацией** | Контроль мяча, дриблинг, пас и первый приём, слабая нога, жонглирование и координация. У каждого упражнения анимация техники, шаги, таймер, частые ошибки, советы по безопасности и варианты попроще и посложнее. |
| **План подстраивается** | После упражнения ребёнок отмечает «легко / нормально / тяжело», и уровень плана растёт или снижается. |
| **Тесты навыков** | Пять измеримых тестов с нормами по возрасту: «прошлый раз 42 → сегодня 55 (+31%)». Карта навыков и достижения — без рейтингов детей. |
| **Видео-самопроверка** | Снимаешь себя и сверяешься с чек-листом тренера. Видео не покидает телефон. |
| **Для тренеров** | Простая форма, чтобы поделиться упражнением; оно приходит команде на почту уже оформленным. |

## Что где лежит

| Папка | Что это |
|---|---|
| [`lite/`](lite) | **Приложение, которое работает сейчас.** Чистые HTML, CSS и JavaScript — без фреймворков и сборки, ~140 КБ в gzip. |
| [`config/commons/football`](config/commons/football) | **Открытая база упражнений** (Open Sport Commons): карта навыков, 60 упражнений, 5 тестов и рубрики для видео — каждое на трёх языках. |
| [`apps/api`](apps/api), [`apps/web`](apps/web) | Полная платформа в разработке: аккаунты, модерация на сервере, AI-планировщик и AI-видеотренер (Bun, Hono, React). |
| [`docs/`](docs) | Инструкция по эксплуатации и скриншоты. |

## Как запустить у себя

Приложение — это статичные файлы, подойдёт любой веб-сервер:

```bash
cd lite
python3 -m http.server 8080
```

Откройте http://localhost:8080. Если вы поменяли упражнения в `config/commons/football`, пересоберите данные приложения:

```bash
python3 lite/build_data.py
```

Полная платформа (`apps/`) запускается через [Bun](https://bun.sh): `bun install`, `cp .env.example .env`, `bun run dev`.
Подробности — в [английском README](README.md#run-locally) и в [docs/runbook.md](docs/runbook.md).

## Как добавить упражнение (без GitHub)

1. Откройте приложение и нажмите **«Тренерам»**.
2. Опишите упражнение: что развивает, как выполнять, частые ошибки, как упростить и усложнить, безопасность.
3. Подтвердите, что имеете право поделиться им по открытой лицензии CC BY-SA 4.0.
4. Нажмите **«Отправить письмом»** — упражнение уйдёт команде на **work@koz-ai.com** уже оформленным. Видео или фото можно прикрепить к письму.

Каждое упражнение проверяет тренер, прежде чем оно появится в приложении. Авторство сохраняется.
Если вы пользуетесь GitHub — [предложите упражнение](../../issues/new?template=drill.yml) или пришлите pull request, см. [CONTRIBUTING.md](CONTRIBUTING.md).

## Честность про ИИ

Стартовые упражнения подготовлены с помощью ИИ. Пока их не проверил настоящий тренер, они помечены как
черновик сообщества, а в приложении у каждого написано «Проверка тренером: идёт». Эти отметки никогда не скрываются.

## Безопасность детей и приватность

- У ребёнка не спрашивают почту, пароли и фамилию; профили и прогресс хранятся в браузере.
- Нет публичных профилей, рейтингов детей, переписки и рекламы.
- Видео для самопроверки никуда не загружается.
- У каждого упражнения есть советы по безопасности, написанные для ребёнка, который тренируется без взрослого рядом.

Нашли проблему с безопасностью? См. [SECURITY.md](SECURITY.md).
